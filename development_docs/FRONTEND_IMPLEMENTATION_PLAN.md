### 1.3 使用目标与功能需求

使用者是办公室桌面环境中的数据管理员。主任务是判断当前服务和数据是否可用、阅读并测试接口、定位更新失败步骤、检查上游调用与通知投递。界面采用中文、浅色、中等信息密度，并支持小屏排障。

| 编号 | 模块 | 必须交付的需求 |
| --- | --- | --- |
| R01 | 登录与控制台框架 | 管理员登录、会话恢复、退出、失效处理；七项导航、面包屑、环境与用户信息、403/404 页面 |
| R02 | 运行总览 | 查询、更新、日志状态分别呈现；当前数据组合、发布/检查/计划时间、当前任务、异常入口、十四源摘要 |
| R03 | 接口中心 | 九业务接口、十四源接口、管理接口说明与行政班待定说明；可搜索目录、Endpoint、参数、请求和响应案例、调用记录入口 |
| R04 | 在线测试 | 每个接口详情内唯一测试入口；弹窗上方填参，下方展示同一次实际响应的 JSON、表格、响应头及适用的课表/组织树；可追踪日志 |
| R05 | 九业务结果 | 两类成绩、两类课表、组织、学生、教职工、教师教学班及教学班学生全部覆盖；保留分页、空值、数据时间和关系一致性 |
| R06 | 更新事件与操作 | 列表、详情、操作树、两份构建与发布、逐表/逐页进度、失败证据；立即增量、强制全量、单表更新、失败重跑及受理恢复 |
| R07 | 数据源 | 十四源状态、主键、检查时间、已确认进度、本次窗口、最近失败、源文档及关联任务/上游日志 |
| R08 | 日志中心 | 接口调用、更新操作、原数据接口、管理审计；历史查询、详情、关联跳转、实时流、断线恢复与单源故障处理 |
| R09 | 通知与邮件设置 | 通知决策、逐人投递及尝试详情；收件人、开关、已支持规则、版本冲突、显式测试邮件；邮件可不启用 |
| R10 | 系统状态与维护 | 服务与依赖、配置和探测状态、双日志源、缓冲/容量、运行和部署配置区分；保留期设置、受保护日志清理 |
| R11 | 通用质量 | 加载/未操作/空结果/错误/未知/过期状态；键盘、焦点、响应式、对比度、长文本、有界请求和离线静态部署 |

运行事实必须可追溯：进程存活不代表业务就绪，采集达到 100% 不代表发布完成，202 只表示受理，SMTP 接受不代表邮箱送达。未知时间、容量、数量和状态保持未知，不填入当前时间、零或绿色成功状态。

本轮不包含任意 SQL、业务数据编辑、人员画像、数据导出、通用账号管理、任意 URL 代理或无契约支撑的恢复/回滚提交。行政班独立查询保留待定说明，不用教学班接口替代。

### 1.5 完整交付前必须关闭的契约差异

这些差异纳入 F00 跟踪。已有接口支持的页面可先实现，依赖缺失的功能不得按完整需求勾选完成。

| 差异 | 当前证据与处理要求 |
| --- | --- |
| 管理接口目录与行政班条目 | `/admin/v1/apis` 当前仅有 23 个业务/源条目。管理接口说明整理为受版本管理的前端文档数据，链接专用操作页面；行政班作为明确不可执行的补充说明，不伪造服务端目录 ID |
| 更新、通知等列表筛选 | 更新列表已在 F07-02 支持受理时间/模式/状态/任务号和游标；通知及日志仍各有允许字段。图片中的时间、结果、HTTP 码、耗时等筛选逐项对照；需要全历史筛选而 API 不支持的，登记后端增补，不能仅筛当前页后宣称全量结果 |
| 游标与数字页码 | 运维列表使用游标，不提供可信总页数。采用“加载更多/上一批”等方式；业务分页按业务协议展示页码，不能照搬图片中的总数及数字分页 |
| 目录 schema 与中文文档 | 现有目录为自定义 `Field` 结构，不等于标准 JSON Schema/OpenAPI；用途多为操作 ID。需做类型适配和中文说明，复杂默认值/组合规则从正式业务契约补齐并随版本核对 |
| 接口就绪与环境 | 目录 `readiness` 当前为 `unknown`。本地业务结合真实健康状态判断；未知不画为可用。上游不存在预探测事实时标“未探测”，通过受控单页测试获得结果；当前单环境部署不提供虚假的环境选择器 |
| 测试执行与历史 | 本地业务使用同步查询代理；`/admin/v1/api-tests` 仅受理上游源测试。历史追溯复用现有双日志库，在日志页筛选与游标分页，使用真实 request_id/test_run_id；不新增统一测试历史列表要求。近期内存摘要只作辅助，刷新清空 |
| 通知规则 | 当前规则为 `source_schema/task_failed/source_test_failed`。图片和原设计中的其他服务/容量阈值、合并窗口等不能作为已支持配置；目标规则需后端补齐后开放 |
| 响应 code 描述冲突 | 接入包有“业务原协议数值 code”的描述，但当前本地业务 transport 和目录示例使用 `code: "ok"` 等字符串；上游示例使用数值 code。按链路分别建模并记录文档修正，禁止全局转换 |
| 恢复与回滚 | 缺少可提交契约的恢复/回滚只呈现状态和说明；既有失败重跑与单表补齐正常接入。新增执行按钮须有独立契约及验证 |

## 二 方案

### 2.1 F00 固定实施基线

关联需求：R01 至 R11。交付物：接口对照表、差异清单、页面清单、类型与样例基线。

- [x] F00-01 将 28 张图与 R01 至 R11 建立追踪关系，固定布局与关键状态；记录需要按现行契约修正的标签、字段和控件。
- [x] F00-02 核对 `internal/admin/`、`internal/operations/`、业务 DTO 及接入样例，逐端点登记方法、路径、请求、响应、错误、分页及可用条件。
- [x] F00-03 逐项处理 1.5 的契约差异，标明前端可完成部分、后端增补内容和验收条件；未关闭的完整需求保持待办。
- [x] F00-04 为九业务接口和十四源建立有版本的合成样例，覆盖成功、空、null、失败、未知及过期；样例明确限开发和测试使用。
- [x] F00-05 固定本轮技术方案：沿用 Vue/TS/Vite、自有 CSS 与 fetch；计划新增 Vue Router 支持详情路由，按需补充状态逻辑测试工具。依赖兼容性检查后锁定 lockfile，不批量升级既有依赖；不因旧文档建议而整体引入 Element Plus。

F00-01 证据：[图稿追踪基线](FRONTEND_VISUAL_BASELINE.md)、[逐步开发与复核记录](FRONTEND_EXECUTION_LOG.md)。其余步骤及页面验收保持待办。

### 2.2 F01 工程组织与公共请求层

关联需求：R01、R11。以增量迁移保持现有登录、九接口查询、任务及进度能力可回归。

建议目录如下，实施时移动文件并同步引用，不另建一份重复业务实现：

```text
frontend/src/
  app/                 路由、会话、启动与全局状态
  layouts/             控制台框架
  pages/               登录、总览、接口、更新、数据源、日志、通知、设置
  components/          表单、表格、状态、时间、复制、弹窗和抽屉
  features/            测试会话、业务结果、操作树、日志流、通知与受控动作
  api/                 HTTP 客户端、DTO、领域端点和错误映射
  composables/         请求取消、轮询、游标与可见性
  styles/              Hub 令牌、基础样式和布局
frontend/e2e/          浏览器协议与交互测试
frontend/gateway-e2e/  真实网关与部署验证
```

- [x] F01-01 拆分 `App.vue` 的会话与路由职责，按页面懒加载；明确 KeepAlive 页面的激活/停用清理，避免隐藏页面继续请求。
- [x] F01-02 演进 `api.ts`：支持 GET/POST/PUT、外部 AbortSignal、超时、响应头、非 JSON 错误与按领域解释错误码；管理设置冲突、日志游标过期和业务快照失效分别处理。
- [x] F01-03 在统一请求结果中保留 `X-Request-ID`、`X-Query-Snapshot`、`X-SICP-Combination`、`Location`、`Retry-After` 等允许响应头；大整数标识、revision 和 sequence 保持字符串。
- [x] F01-04 统一请求代次与会话代次隔离；切页、改条件、关闭弹窗、退出登录中止等待，迟到响应不得写回新页面或新会话。
- [x] F01-05 分开封装任务的 header `Idempotency-Key` 与新异步作业的 JSON `idempotency_key`；受理不明时保持原键和原载荷，按原作业位置查回。
- [x] F01-06 仅对必要的待确认操作保存短期会话恢复信息，绑定环境/主体/动作并设置过期；不存密码、CSRF、人员结果或源响应，退出即清理。
- [x] F01-07 为只读轮询设定可见性、退避和在途请求上限；有副作用的请求不走通用自动重试。

### 2.3 F02 Hub 主题与基础组件

- [x] F02-02 固定桌面布局：顶栏约 56px，侧栏 216px/折叠 64px，内容边距 24px；标题 24px、区块标题 18px、正文 14px，系统中文字体；控件圆角 6px、面板 8px、表格行高约 44px。
