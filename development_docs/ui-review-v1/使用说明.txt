SICP UI 图片评审 V5：接口中心统一版
修订日期：2026-10-10

使用方式
1. 浏览器打开 index.html，无需启动服务或安装依赖。
2. 按分组或关键词查找，点击放大，使用方向键切换、Esc 关闭。
3. 评审意见保留在当前浏览器，使用“导出评审意见”保存 JSON。旧版意见不自动代表对新版的认可，请重新核对。
4. 分享完整文件夹或 SICP-UI-review-v5.zip；压缩包同时包含前端设计方案。

本次合并
28 张图片已统一采用接口中心信息架构：查看 Endpoint、请求参数和 Response 示例，再打开当前接口的在线测试弹窗。06—14 展示同一测试结果的表格、课表、组织树及详情；未实现接口保留说明并禁用测试。
全局导航：运行总览、接口中心、更新事件、数据源、日志中心、通知中心、系统设置。
“业务查询”作为在线测试的业务用途，不再占用独立一级导航。桌面采用当前接口测试弹窗，上方填参、下方查看结果；移动端采用全屏测试层，关闭返回接口详情。

评审顺序
03 接口目录 → 04 Endpoint、参数与响应示例 → 05 在线测试 JSON → 06—14 业务结果视图 → 28 上游接口。其余页面统一导航，27 为移动端适配。

交付范围
仅更新设计图、图库与设计说明，实际前端代码未修改。图片均为设计预览与示例数据，精确字段及协议以 sicp-api-design.md 和 FRONTEND_DESIGN_PLAN.md 为准。
内置 image_gen 完成图片修订，提示词和输出来源见 api-center-revision.json；历史生成记录见 prompts.json；最终图片尺寸、大小和 SHA-256 见 manifest.json。03—14 已有合并稿逐图复核后沿用，01 登录无独立业务查询导航，无需重绘。
SICP-UI-review-v1.zip 为旧版归档，请使用新的 V5 压缩包分享。
