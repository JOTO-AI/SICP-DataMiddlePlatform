# 前端主题令牌（F02-01）

实现位置：`frontend/src/styles/tokens.css`。沿用 V5 Hub 的品牌蓝 `#195BFF`、悬停 `#0F48D8`、背景 `#F7F8FA`、面板白、正文 `#1A1C19`、次级文字 `#667085`、成功 `#16823C`、错误 `#D92D20`。旧组件变量通过语义别名接入，不重复硬编码色值。

浅底上的小号文字单独指定：选中蓝字 `#1D4ED8`，浅蓝底上的次级文字 `#475467`，浅绿底成功字 `#126E33`。警告采用独立橙棕 `#B54708` 配 `#FFF4E5`；错误红配 `#FFF7F6`。品牌/状态基色保留原值，语义文字按实际底色满足可读性。

弱提示与 placeholder 不使用 Hub 清单中对比不足的 `#9AA3AF`，统一为 `#667085`；输入边界为 `#7E8798`，确保白底控件边界至少 3:1。聚焦使用 `#2563EB`，状态均保留文字说明。

验证命令：`npm.cmd run check:theme --prefix frontend`。当前 16 组语义配色通过，正文/提示至少 4.5:1，控件边界和焦点至少 3:1。其中弱文字/浅灰底 4.55:1，错误/浅红底 4.58:1，警告/浅橙底 4.99:1。交互控件的所有状态与禁用行为将由 F02-06 进一步统一，不能将本步视为完整可访问性验收。

F02-01 已视觉检查桌面总览、390px 初始化总览和登录错误，截图位于本地 `artifacts/frontend-f02-01/`。尺寸、七模块导航及小屏抽屉尚属后续步骤。

## 桌面尺寸（F02-02）

布局与排版尺寸同样定义在 tokens.css：顶栏 56px、侧栏 216px、折叠 64px、内容边距 24px；标题 24px、区块标题 18px、正文 14px；控件圆角 6px、面板 8px、单行表格 44px。中文使用既有系统字体栈。

桌面折叠按钮具有 aria-expanded / aria-controls，折叠后的导航仍保留 aria-label 与 title，可用键盘切换页面。折叠状态只在当前应用会话内保留，不新增浏览器存储。1280px 以下暂沿用既有自适应，小屏导航抽屉与自动折叠属于 F02-07。
