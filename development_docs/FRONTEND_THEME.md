浅底上的小号文字单独指定：选中蓝字 `#1D4ED8`，浅蓝底上的次级文字 `#475467`，浅绿底成功字 `#126E33`。警告采用独立橙棕 `#B54708` 配 `#FFF4E5`；错误红配 `#FFF7F6`。品牌/状态基色保留原值，语义文字按实际底色满足可读性。

弱提示与 placeholder 不使用 Hub 清单中对比不足的 `#9AA3AF`，统一为 `#667085`；输入边界为 `#7E8798`，确保白底控件边界至少 3:1。聚焦使用 `#2563EB`，状态均保留文字说明。

验证命令：`npm.cmd run check:theme --prefix frontend`。当前 16 组语义配色通过，正文/提示至少 4.5:1，控件边界和焦点至少 3:1。其中弱文字/浅灰底 4.55:1，错误/浅红底 4.58:1，警告/浅橙底 4.99:1。交互控件的所有状态与禁用行为将由 F02-06 进一步统一，不能将本步视为完整可访问性验收。

F02-01 已视觉检查桌面总览、390px 初始化总览和登录错误，截图位于本地 `artifacts/frontend-f02-01/`。尺寸、七模块导航及小屏抽屉尚属后续步骤。

## 桌面尺寸（F02-02）

布局与排版尺寸同样定义在 tokens.css：顶栏 56px、侧栏 216px、折叠 64px、内容边距 24px；标题 24px、区块标题 18px、正文 14px；控件圆角 6px、面板 8px、单行表格 44px。中文使用既有系统字体栈。

桌面折叠按钮具有 aria-expanded / aria-controls，折叠后的导航仍保留 aria-label 与 title，可用键盘切换页面。折叠状态只在当前应用会话内保留，不新增浏览器存储。1280px 以下暂沿用既有自适应，小屏导航抽屉与自动折叠属于 F02-07。

## 控件状态（F02-06）

- 默认：白底与独立控件边界；输入/选择/文本域悬停用品牌边界；错误悬停仍保留错误边界。按钮、链接和折叠说明提供悬停反馈，主按钮按压保持深蓝。
- 焦点：键盘 :focus-visible 使用 3px 蓝色外圈，标签栏改为内偏移以避免滚动容器裁切；原生 checkbox/radio 保持浏览器键盘行为。
- 禁用：移除 fieldset 和按钮整体透明度；禁用文字 #667085 / 背景 #F3F5F8 为 4.55:1，边界 3.31:1；原生 :disabled 同时覆盖 fieldset 的后代，说明文字不会一起褪色。
- 加载：已接入表单/按钮的 aria-busy、禁用与明确等待文字；不依赖旋转动画。取消/停止等待按相应组件语义保留。
- 错误：aria-invalid 或原生 user-invalid 显示红色边界，具体错误用文字并关联输入；不会把错误只表示为色块。warning 使用独立警告底色。
- 20 组令牌配色检查加浏览器 computed style 检查覆盖 placeholder、禁用控件、主按钮默认/hover、浅蓝提示和错误/警告。prefers-reduced-motion 禁用动画与过渡。

## 三档响应式（F02-07）

- ≥1280px：默认 216px 完整侧栏，可手动折叠为 64px。
- 768–1279px：自动 64px 折叠侧栏；保留 aria-label/title，表单双列、维护与详情上下排列。
- <768px：隐藏侧栏，顶栏按钮打开全屏主导航抽屉，切换路由自动关闭；Escape 返回触发器，切换路由焦点到主内容，扩大到平板时关闭抽屉并释放滚动锁。表单/概览/任务单列，Drawer 详情撑满视口并内部滚动。
- 宽表/JSON 自身滚动；参数说明表至少 640px 保持编号可读。小屏及 coarse pointer 控件/标签点击区约 44px，checkbox/radio 图形保留原生大小，整个标签可点。
- 移除旧 1150/850/600 互相叠加的页面布局规则；现有三路由共享布局，F03 新导航模块仍在后续步骤。
