## 命令与证据

工作流：`.github/workflows/ci.yml`（Linux CI）。主命令：

```bash
./scripts/check.sh
go test -race -count=30 ./internal/service
docker build --platform linux/amd64 -f deploy/Dockerfile --build-arg SERVICE=query-service -t sicp-query:p01 .
docker build --platform linux/amd64 -f deploy/Dockerfile --build-arg SERVICE=sync-worker -t sicp-worker:p01 .
```

`check.sh` 执行 gofmt 检查、go vet、`go test -race -count=1 -coverprofile=artifacts/coverage.out -json ./...` 和两个 Linux 静态构建。退出码、通过/失败/跳过数及 Actions 链接在执行完成后补录。JSON 与覆盖率随 `linux-unit-evidence` artifact 保存。

测试仅使用仓库内合成配置/JSON、FakeClock、固定随机源、依赖工厂替身与本进程回环 listener。未调用真实上游、未读取人员样本、未发送邮件；I01–I06 尚未执行，实际 Linux 进程信号链路留给 I06。
