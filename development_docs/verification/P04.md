## P04.06：全量替换质量门槛

- `merge.Full` 只接收实际 `staging.Sealed` 句柄，拒绝 nil/零值和增量模式，逐目标表页 ReadPage 重新验证载荷摘要；完整性由此前 OpenSealed 对十四类实际页证据验证，不能传入 Complete=true 代替。
- 基线与范围：SourceDigest 绑定 table、可信配置范围 ID 与排序后的原始源对象；Full 对当前源证据重新计算并匹配上轮可信构建保存的摘要。空/不符摘要、范围不匹配拒绝。调用方不能把 SQL 还原行重新算摘要冒充旧基线。范围 ID 由持久任务/源配置提供；现有源文件未存上游身份，不声称单凭文件证明上游范围。
- 质量：显式按表设置 MinimumRows、MaximumDeletedRows，零删除上限禁止删除；已有非空表清空默认拒绝，只有显式 AllowEmpty 且删除阈值允许才放行。全量缺失主键通过全部门槛后删除，增量路径仍保留；所有错误均无候选输出。
- 历史表：全量存在的键仍对本轮所有历史与当前行共同检查冲突/最新；不先折叠再漏掉当前时间冲突；普通表重复输入拒绝，采集分页亦提前阻止。
