## Code review

已按方案逐项人工复核并修复以下问题，复核后未发现本步阻塞项：

1. 草稿旧 to 会排除订阅后事件：增加 live 固定 from/to=null 和首次窗口边界，续页不重算。
2. 草稿不区分 raw/correlation：入口复用既有 HMAC，显式格式，签名和输出只存摘要；增加独立预期，64 字符 raw 不按长度猜测。
3. 跨权限草稿返回 400：改为 403；仍须管理鉴权，游标不授予权限。
4. 数据库恢复后先按倒退 floor 报参数错误：先比较合法 epoch，旧 epoch 统一重查；历史和实时保留不同清理边界。
5. 密钥不能轮换：增加不可变 keyring/key_id，复制配置输入；换签不延期，撤销后拒绝。
6. 时间解析可能接受超精度零尾数、单数小时和非法时区偏移：按 RFC3339 和微秒边界限制。
7. 历史翻页不能改变实时起点：StreamStart 固定首次 H 与原期限。
8. 空集合/未知值/大序号明确区分；请求先限长再解析，错误不回显内部文本。audit/test 仅声明契约，旧 writer 兼容留给 P28。

本轮为主代理人工 review，未使用独立审查代理。静态复核不等于运行正确性证明。
