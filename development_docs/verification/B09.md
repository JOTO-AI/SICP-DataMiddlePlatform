实现与静态 code review 完成；单元、race、Playwright 仅在 GitHub 执行，结果待确认。提交 SHA 可通过本文件的 git 历史定位。

写入计数来自成功提交的批次；内容核对计数来自逐列比较成功的行；业务计数来自真实请求与响应完成后的案例。计数仅更新进程内 tracker，既有 10 秒心跳聚合落库，不逐行写控制库。表、M/S、副本子阶段隔离；带 scope 序号的回调不能污染后续阶段。目标生成仍显示已有表列表，未接入的工作量保持未知。

新增 completed / total_known / total、batches、unit、detail、last_progress_at、attempt、cumulative_completed、cumulative_elapsed_ms。当前执行器生命周期内同阶段重入保留累计，进程重启不会伪造未落盘历史；跨进程历史以既有持久阶段事件为准。旧进度 JSON 仍可读取，新增数据仍受控制库大小、权限及所有权代次限制。

页面不以心跳声称正在写入；超过 45 秒没有真实进展单独提示，心跳过期优先提示状态待确认，终态优先显示结束/失败。总耗时使用任务 started_at，终态使用 finished_at（旧记录缺失时停在最后心跳）。只对已知正数分母显示工作量进度条，100% 不代表 ready / 发布。未提供推测剩余时间。
