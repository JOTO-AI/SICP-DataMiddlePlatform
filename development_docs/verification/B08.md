BeginFenced 在构建指标 context 内记录获得全部围栏后到提交／回滚应答的单调耗时 `fenced_hold_ns`；已有锁获取 RPC 计时继续记录等待。两者不得混称纯 PostgreSQL 等待；应答未知不推断物理 SQL 已结束。

仅展示进度 SaveWorkProgress 改为乐观读取所有权和任务状态，不取得构建长期持有的 execution／slot 锁。保存带所有权代次，冲突更新不允许低代次或旧时间覆盖新进度；读取过滤与当前任务代次不匹配的旧包。展示数据不能授权 ready、水位、接管或发布。真正状态转换和物理导入继续使用原围栏及 SQL 结束证明。
