## 2026-10-13 单管理员默认配置

按用户要求保留一个管理员登录入口并默认授权全部已实现管理动作，移除标准 Compose/.env.example 中三项日志密钥/令牌和四项 READ/MAINTENANCE URL。SNAPSHOT_KEY 通过版本化 HMAC 用途标签派生稳定的日志游标签名密钥与内部服务令牌；无需额外配置，跨实例一致，轮换后旧游标失效。显式配置仅为直接进程兼容保留，Compose 不再加载。管理员密码仅传给 worker。

Runtime 自动从固定日志目标及本服务凭据构造读取连接，worker 同时使用该连接执行受限维护；同 DSN 连接池去重。追加 logs_007/upstream_logs_006，授予服务角色相应只读组、仅 worker 授予受限维护组，未修改旧迁移 checksum。内置日志实例已有服务 LOGIN；外部实例需按部署规范预建对应服务 LOGIN 及成员关系。

人工 review 发现并修复两个影响默认使用的旧缺口：内部网关 8080 补充日志代理/SSE 路由，外部 8443 继续拒绝 /internal；迁移后旧缓冲改走 append_event，保留原平台目标、ID、载荷和未知提交重放，不再使用已被禁止的直接 INSERT。历史 call/attempt 不自动搬库。

新增/调整测试源码覆盖默认密钥跨实例/重启一致、用途隔离、轮换，单管理员所有动作与匿名拒绝，实际装配自动连接、worker-only 维护、重复池回收，真实 PG 服务角色授权和网关内外部路由边界；旧排空用例的数据库替身拒绝直接写入。未执行这些测试。
