# P23 教学班学生查询复核

## P23.01（2026-10-12）

StudentRows 只为共用成员组件选定的关系学号补充基本、学籍、单位及行政班，按集合批量读取；不使用严格学生档案配对，不按当前行政班补人，不按学籍状态删除成员。基本/学籍缺档仍返回学号；单位/班级缺档保留编号/null 名称。归属使用当前已发布记录。

source_updated_at 包括组合判定排课、本成员全部重复关系及实际基本/学籍/单位/班级；组合排课时间先计算一次，每个成员继续折叠自身记录，避免将别人的资料时间纳入。所有关联和时间处理共用预算/取消检查；晚期错误返回 nil。

code review：核对八接口不共用严格学生匹配，以免缺档成员被删除；无关系的同班学生及其错误时间不会被读取；缺教师/联系方式不参与这个接口。手写完整名单验证两个真实成员、缺基本的成员、当前归属和时间；分别删除各附属表仍保留成员，覆盖每种参与表最大时间、重复基础、错误字段、关联 SQL 和晚期时间错误。gofmt 与 diff --check 通过，无剩余阻断意见；测试未执行。
