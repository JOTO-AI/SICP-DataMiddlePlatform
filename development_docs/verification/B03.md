# B03 游标索引、关联索引与统计信息

实现和静态 code review 完成，GitHub 验证待确认。

`business_003` 增加十四表主键的 C 排序索引、成绩和学生课表的学号＋主键索引，以及排课的教学班＋课程＋主键、学年＋学期＋主键索引。原主键和已应用迁移不变。索引列来自实际参数化查询条件；教师工号仍做完整 token 匹配。

候选检查在 query 角色下检查原主键，并核对新索引的表、列顺序、C collation、btree text_ops、升序、有效／就绪／存活状态、非部分／非表达式索引。只匹配名字不算有效。

表导入结束后、释放构建资格前执行 ANALYZE，确认提交后才能返回表完成；失败不能写完成账本。迁移给予 worker 源表 MAINTAIN 权限，执行前检查权限，避免 PostgreSQL 静默跳过无权限表。query 权限不扩大。

部署需在受控窗口对 M0/M1/S0/S1 执行事务迁移，不能在现有事务迁移器内使用 CREATE INDEX CONCURRENTLY。重复执行使用原有 checksum 账本；DDL 失败整笔回滚。先迁移后部署新 worker；回退二进制可保留新索引和权限，不删除历史迁移。

BT03 检查迁移与查询索引定义一致、DDL 失败回滚、统计更新失败不完成；既有 replay/checksum/参数化测试继续执行。新增 I01 场景在 en_US.utf8 的四槽位检查索引、100001 行后台／前台预算差异、中文与前导零跨页、同名错误索引拒绝，并保存首／中／末页和学号查询 EXPLAIN ANALYZE BUFFERS JSON。没有禁用顺序扫描。

本地仅 gofmt 与差异检查，未运行 SQL 或测试。EXPLAIN 结果、WAL／磁盘和导入成本仍待 GitHub 工件，不声明已证明性能提升。

设计依据：[PostgreSQL 18 索引目录](https://www.postgresql.org/docs/18/catalog-pg-index.html)、[ANALYZE 权限与行为](https://www.postgresql.org/docs/18/sql-analyze.html)。
