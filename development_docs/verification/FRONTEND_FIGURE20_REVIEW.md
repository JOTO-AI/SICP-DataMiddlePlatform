起点：5879288。本步 V05 按 20-log-detail.png 实现独立日志详情，并把日志列表行的“查看日志详情”直接连接到此页。

## 实现与图稿边界

- 标题/结果/请求号与 HTTP、业务码、ms 耗时、来源摘要；概览、脱敏详情、关联记录三个标签；错误横幅；左侧执行时序与右侧基本信息；下方关联记录表、折叠错误诊断和脱敏 JSON。
- 详情行使用源、事件号、世代和序号定位，拒绝轮换后身份不匹配的结果；返回原列表保留当前筛选及已读取批次。离开详情去其它业务页则清理旧列表，离页暂停实时流及请求。
- 执行时序首次只显示所选的真实事件；“读取关联时序”按实际关联号读取同源同世代、发生时间前后各一天的记录。分页每批 50 条，最多 20 批，微秒排序，发生时间未提供的排后；相同时间不推断因果。入库时间单列，不作为执行阶段。
- 图稿中的示例错误、组合 C100、完整四阶段时间线和“关联日志尚未入库”不能从当前 DTO 自动确认，故不照抄。关联表明确标为“待查询关联记录”，点击后沿用现有按关联号查询；HTTP 和业务码不互相推断。
- 耗时仍使用字符串精确换算 ms。小数秒保留后端原有精度。长 ID 省略展示、悬停显示完整值，复制仍为完整 ID。完整错误正文可展开查看，JSON 仍有显示/复制上限。
