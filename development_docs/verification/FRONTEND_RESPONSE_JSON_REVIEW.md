# V10 在线测试响应 JSON 格式化复核（2026-10-16）

## 实现与 code review

在线测试的业务响应、管理作业响应及本页源数据默认按两空格缩进、换行展示，支持“格式化 JSON / 查看原文”切换。格式化只改变 JSON token 之间的空白；JSON.parse 仅校验语法，不使用解析后的数字重新序列化，保留大整数、小数、指数、重复字段、字符串转义和前导零。

JsonText 的 pretty 为可选能力，既有日志等原文显示不受影响。继续使用纯文本插值，不执行响应 HTML。复制与当前显示一致，切换模式/响应会清理复制反馈并收起内容。默认显示 4096 字符，展开最多 65536 字符；2 Mi 字符输入、4 Mi 字符输出及 64 层深度预算避免无限格式化，非法、不完整或超预算内容保留原文。

复核格式扫描、字符串转义跳过、数字原文保留、空容器、边界预算、剪贴板异步状态、源结果与业务结果、切换模式无额外请求。已修复复核发现的显示模式缺少 active 选中样式。
